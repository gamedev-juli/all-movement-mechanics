Welcome. This repository holds a Godot 4.4 project where I implemented a first-person 3D platformer, with every movement mechanic I could think of.

You can play the "game" (it's more a tech demo) on [itch.io](https://gamedev-juli.itch.io/level-1). No need to download anything, just play in the browser.

Without watching the [Youtube devlog](https://youtu.be/U5A_JArREUc), none of this will make much sense though.

## Good to know

There is no tutorial, sound, settings, or win-condition, and the game has never been playtested or properly debugged. It only works with a controller.

The game has 5 simple levels to play. The goal is to go from the gold platform to the diamond one as fast as possible.

The 26 mechanics are:

1. gravity + sliding

2. look around

3. run + head bobbing

4. jump

5. mid-air movement (like Quake)

6. moving platforms

7. ledges

8. double jump

9. dash

10. crouch

11. terminal velocity

12. swim

13. climb

14. glide

15. wallrun

16. grapple
    
    1. basic grapple, e.g. Uncharted, Tomb Raider
    
    2. Titanfall 2 grapple
    
    3. Sekiro grapple
    
    4. Spider-Man webslinging

17. ground pound

18. slingshot

19. rail grinding

20. flying
    
    1. Minecraft creative-style flying
    
    2. Minecraft elytra-style flying (with fireworks)

21. teleportation (with portals like in Portal)

22. alter gravity
